---
name: Google AI Studio imports
description: Access constraint for bringing Google AI Studio apps into this project.
---

Google AI Studio app links are not necessarily public download links; an unauthenticated request can redirect to Google sign-in.

**Why:** The shared app URL inspected during project setup required an authenticated Google session, so source, prompts, settings, and assets could not be pulled automatically.

**How to apply:** Ask the user to upload an exported project bundle or provide an accessible export/share link before attempting an import.
